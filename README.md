                ## Running Locally:

                If you wanna run it locally, here's a guide.

                Otherwise, visit the deployed version:

                **https://rudragoelbuilderpage.vercel.app**

                ### 1. Install the dependencies

                ```bash
                npm install
                ```

                ### 2. Start the development server

                ```bash
                npm run dev
                ```
